# Net Banking System 

## About the Project

The Net Banking System is a simple Python-based banking application developed using Tkinter. The project provides a graphical interface where users can log in and perform basic banking activities.

The main purpose of this project is to understand how Python can be used to create a simple banking application with an easy-to-use graphical interface.

## Features

* User login with username and password
* View account details and current balance
* Deposit money into the account
* Withdraw money from the account
* Check transaction history
* Apply for different types of loans
* View debit and credit card details
* Submit a customer service complaint
* Change account password
* Logout from the system

## Technologies Used

* Python
* Tkinter
* Datetime module

Tkinter is used to create the graphical user interface, while the datetime module is used to record the date and time of transactions.

## How the Project Works

When the application starts, the user is first shown a login screen. After successful login, the main banking dashboard is displayed.

From the dashboard, the user can select different options such as Account, Deposit Money, Withdraw Money, Transactions, Loan, Debit/Credit Card, Customer Service, and Change Password.

The deposit and withdrawal sections automatically update the account balance and record the transaction.

The loan section allows the user to select a loan type, enter an amount, and submit a loan application.

## Project Objective

The objective of this project is to create a simple banking system that demonstrates basic banking operations using Python and a graphical user interface.

It also helps in understanding Python functions, variables, conditional statements, lists, user input, and GUI components.
